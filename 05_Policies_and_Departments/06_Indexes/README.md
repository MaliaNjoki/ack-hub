# Anglican Church of Kenya – Policies and Departments Indexes

## Overview

This folder contains navigation and reference indexes for the information documented under:

`05_Policies_and_Departments/`

The indexes are designed to improve retrieval by the ACK AI knowledge base without duplicating the substantive content contained in the individual files.

## Purpose

The indexes provide:

* Navigation between related ACK structures.
* File-level references.
* Relationships between governance, boards, departments and policies.
* A controlled way of locating information.
* Support for AI retrieval and cross-referencing.
* Identification of areas requiring further verification.

## Principle: No Duplication

The indexes must **not reproduce the substantive content** of the source files.

Instead, they should:

1. Identify the relevant file.
2. State what subject it covers.
3. Link related structures where useful.
4. Preserve the distinction between different ACK structures.

The source file remains the authoritative location for the detailed information.

## Cross-Reference Principle

Where two files concern related subjects, use a cross-reference instead of copying the same information.

Example:

```text
Board of Mission
        ↓
Mission Department
        ↓
Provincial Secretariat
```

The individual files explain their own roles.

The index only establishes the relationship.

## AI Retrieval Guidance

When a user asks a question involving multiple provincial structures, the AI should:

1. Identify the relevant category.
2. Locate the appropriate source file.
3. Follow cross-references where necessary.
4. Avoid treating related structures as identical.
5. Use the most authoritative source available.
6. Preserve current versus historical distinctions.
7. Report when information has not been verified.

## Structural Distinctions

The following distinctions must remain clear:

### Governance

Includes structures such as:

* Provincial Synod
* House of Bishops
* Standing Committee
* Provincial Boards
* Provincial Commissions
* Constitutional Offices

### Administration

Includes the Provincial Secretariat and its offices and departments.

### Ministry Structures

Includes Boards and ministry-related structures.

### Policy

Contains formally verified policy instruments and related documents.

### Institutions

Includes institutions associated with ACK but not automatically part of the Provincial Secretariat.

## Data Quality

Indexes should be updated when:

* A file is added.
* A file is renamed.
* A structure changes.
* A policy is amended or superseded.
* A governance structure changes.
* An official source provides new authoritative information.

The index should never become a source of outdated information simply because the underlying file has changed.
