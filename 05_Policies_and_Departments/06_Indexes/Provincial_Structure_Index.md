# 7. Important Structural Distinctions

## Board vs Department

A Provincial Board is a governance/ministry structure.

A Department is an administrative or operational structure within the Provincial Secretariat.

They may work together but are not the same body.

## Board vs Commission

A Board is one of the principal provincial structures.

A Commission is a specialised structure with a defined mandate.

The existence of a committee does not automatically make it a Commission.

## Governance vs Secretariat

Governance structures exercise or support constitutional and synodical authority.

The Provincial Secretariat provides administrative and operational support.

## Policy vs Procedure

A policy establishes an approved direction or framework.

A procedure describes how a process is carried out.

The AI should not use these terms interchangeably.

# 9. Duplicate-Control Rule

Before creating a new file, check whether the subject already exists elsewhere in the ACK Hub.

If it does:

1. Use the existing source file.
2. Add a cross-reference if necessary.
3. Do not create a duplicate record.
4. Only create a new file when the subject represents a genuinely distinct structure or document.

This rule is particularly important for:

* Boards
* Departments
* Committees
* Commissions
* Institutions
* Governance offices

# 10. Current and Historical Information

The index does not determine whether a structure is current or historical.

The individual source file must contain:

* Status
* Source
* Date
* Verification information

Where a structure has changed over time, the historical record should be preserved without presenting it as current.
